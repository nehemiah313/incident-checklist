# Incident Checklist

A free tool for the moment you hope never comes: a cyber incident on a defense contract. Prepare before it happens, track the 72-hour DFARS reporting clock when it does.

**Live tool:** https://nehemiah313.github.io/incident-checklist/

## What it does

- **Prepare checklist**: 7 things to have ready before an incident (IR plan, DIBNet access, notification chain, forensic preservation)
- **Active incident tracker**: enter discovery time and get a live 72-hour countdown (turns urgent under 12 hours, flags overdue). Hour-by-hour task lists: 0-4 contain and preserve, 4-24 investigate, 24-72 report, after-72 follow through. Each task explains why it matters.
- **Timestamped incident log**: record every action; it becomes the backbone of your DoD report
- **Report field guide**: the 8 fields your DFARS 252.204-7012 report must include
- **Export**: full incident record as Markdown (checklist state, log, deadline)
- Everything stays in your browser (localStorage only, nothing uploaded)

## Honest framing

File the actual report through the DoD DIBNet portal (dibnet.dod.mil). This tool tracks your response; it does not file for you. Guidance only, not legal advice.
